# MoodNewsGrid

**MoodNewsGrid** — это веб-приложение, которое позволяет читать новости в разных эмоциональных тонах. Оно берёт реальные новости из открытых источников и переписывает их в зависимости от выбранного настроения (радостное, грустное, нейтральное, ироничное), сохраняя все факты.

---

## 📌 О проекте

Проект состоит из трёх основных сервисов, каждый из которых работает в отдельном контейнере:

| Сервис | Назначение |
| :--- | :--- |
| **`database`** | Хранилище новостей (MariaDB) |
| **`server`** | API сервер на базе C++ фреймворка **Drogon** |
| **`llama`** | Сервис для генерации текста на основе **LLM** (llama.cpp) |

---

## 🚀 Быстрый старт

### Требования
- Docker / Podman
- Docker Compose / Podman Compose

### Запуск
```bash
podman compose up --build
```

Сборка образа `llama` может занять какое-то время, так как автоматически загружается модель **YandexGPT-5-Lite** (около **4.9 ГБ**).

После успешного запуска веб-интерфейс будет доступен по адресу:
http://127.0.0.1:5555

## 📡 API Эндпоинты

### 1. Получение списка новостей
**`GET /news`**

Возвращает список всех новостей в формате JSON.

### 2. Получение конкретной новости
**`GET /news/{id}?mood={mood}`**

Возвращает новость по её ID. Если указан параметр mood, в ответ добавляется поле text_with_mood с переписанным текстом в заданном тоне. Параметр mood может принимать следующие значения: happy, sad, neutral, ironic.

## 🗄️ Наполнение базы данных (Seed)

Для первоначального заполнения базы данных используется отдельный режим запуска сервера:

```bash
./server -s
```

При этом:
1. Сервер загружает RSS-ленту из источника (по умолчанию https://www.vedomosti.ru/rss/articles.xml) с помощью библиотеки cpp-httplib.
2. Парсинг RSS (извлечение заголовка, ссылки и описания) выполняется с помощью TinyXML2.
3. Данные сохраняются в базу данных MariaDB с использованием встроенного в Drogon ORM.

---

## 🧠 Переписывание текста с настроением

Для изменения эмоциональной окраски новостей используется отдельный сервис llama, запускаемый в контейнере на базе llama.cpp. Этот сервис принимает HTTP-запросы от основного сервера и возвращает переписанный текст в заданном тоне.

Каждый промпт, отправляемый из сервиса server в сервис llama, содержит требование сохранить все имена, даты, числа, географические названия и цитаты из оригинальной новости.

Сервис llama использует модель YandexGPT-5-Lite, которая автоматически загружается на этапе сборки образа из llama/Dockerfile.
