Проект реализует ленту новостей, где каждую новость можно прочитать в выбранном настроении.

Сервисы проекта:
database - база данных mariadb
server - api сервер на Drogon

server реализует два эндпоинта:
1) GET /news - для получения списка новостей.
2) GET /news/{id} - для получения конкретной новости. Также может включать параметр mood для получения новости в настроении happy, sad, neutral или ironic.

Для первоначального заполнения базы данных новостями используется параметр -s, указываемый при запуске билда сервера. Новости берутся в RSS формате из https://russian.rt.com/rss. Http-запрос к rt.com/rss выполняется используя библиотеку cpp-httplib. Из полученного RSS файла извлекаются элементы title, link и description каждой отдельной новости с помощью библиотеки tinyxml2.
